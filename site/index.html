Who this is for

You already have lifelong muscle memory: copy, paste, undo, save, find, tabs, explorer. Brand-new Vim often says forget all of that. This config asks a different question: why should we have to?

Day one feels like an editor

The familiar layer is first-class. LazyVim and real Vim stay available underneath.

Install

Requires Neovim 0.11+ (LazyVim 8). First launch needs network for plugins.

# backup any existing config
mv ~/.config/nvim ~/.config/nvim.bak 2>/dev/null

git clone https://github.com/KOUSTAV2409/lazyvim-config.git ~/.config/nvim
nvim

On Omarchy, symlink the live theme after clone (README). Shortcuts work without Omarchy; only theme hot-reload needs it.
