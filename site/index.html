Craft over chrome.

Neovim weight instead of another Electron IDE. Grown on Omarchy; theme hot-reload is optional. Shortcuts work anywhere Neovim 0.11+ runs.

Install

Requires Neovim 0.11+ (LazyVim 8). First launch needs network for plugins.

mv ~/.config/nvim ~/.config/nvim.bak 2>/dev/null
git clone https://github.com/KOUSTAV2409/lazyvim-config.git ~/.config/nvim
nvim
